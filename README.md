# Movie Recommendation System

A simple Python-based movie recommendation system that recommends similar movies using their genres and descriptions.

### Features
- Recommends the top 5 similar movies.
- Uses TF-IDF vectorization to process movie text.
- Uses cosine similarity to calculate movie similarity.
- Includes 15 movies.
- Simple command-line interface.

### Technologies
- Python
- Scikit-learn
- TF-IDF
- Cosine Similarity

### Installation
Install the required dependency:

```bash
pip install -r requirements.txt
```

### Run the Project

```bash
python recommendation_system.py
```

Enter a movie title to see recommendations. Type `quit` or `exit` to close the program.
